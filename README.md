# Portfolio_me 💼

Personal portfolio website for Damilola Olarewaju — a builder, educator, Computer Science student, and aspiring AI Engineer.

The site presents Damilola's background, technical interests, projects, academic planning tools, and contact channels in a responsive multi-page experience.

🌐 **Live site:** [portfolio-me-tau-flax.vercel.app](https://portfolio-me-tau-flax.vercel.app)

## Pages

- **Home** — Introduction, current status, and primary calls to action
- **About Me** — Education, aspirations, technical skills, and interests
- **Projects** — Study Buddy, TrustLens, and MindClone project showcases
- **Academic Planner** — A dedicated planning experience for academic work
- **Contact** — Contact information and a client-side contact form

## Getting started

This is a static website and does not require a build tool or package manager.

### Run locally

1. Clone the repository:

   ```bash
   git clone https://github.com/DamilolaOlarewaju/Portfolio_me.git
   cd Portfolio_me
   ```

2. Open `index.html` directly in a browser, or start a local server:

   ```bash
   python -m http.server 8000
   ```

3. Visit [http://localhost:8000](http://localhost:8000).
